Команда `docker import` используется для создания образа из архивного файла или из данных, прочитанных из стандартного ввода.

Чтобы импортировать контейнер обратно в образ, вам необходимо сначала создать архивный файл из его файловой системы. Для этого выполните следующие шаги:

1. Зайдите обратно в контейнер:
      docker start -i <container_id>

2. Создайте архив контейнера:
   В командной строке контейнера выполните:
      tar -c -C / . | gzip > container.tar.gz
   
   Эта команда создаст архив `container.tar.gz`, который содержит файловую систему контейнера.

3. Выполните импорт архива в новый образ:
      cat container.tar.gz | docker import - myimage:latest
   
   Эта команда принимает данные из архива, читаемого из стандартного ввода (с помощью `cat`), и создает новый образ с тегом `myimage:latest`.

После выполнения этих шагов появится новый образ `myimage:latest`, который содержит файловую систему вашего контейнера. Обратите внимание, что `<container_id>` и `myimage:latest` - это примеры идентификатора контейнера и тега образа; вы можете выбрать соответствующие значения для вашего случая.
``````
``````
Если у вас уже есть контейнер Nginx и вы хотите создать архив его файловой системы, вы можете использовать ту же команду, но заменив корневую директорию на расположение файлов Nginx в контейнере. Обычно файлы Nginx находятся внутри контейнера по пути `/etc/nginx/` для конфигурационных файлов и `/usr/share/nginx/` для файлов сайта.

Вот как это может выглядеть:

docker run --name temp_nginx nginx   # создаем временный контейнер nginx
docker cp temp_nginx:/etc/nginx/ ./nginx_configs    # копируем конфигурационные файлы 
docker cp temp_nginx:/usr/share/nginx/ ./nginx_files    # копируем файлы сайта
tar -czvf nginx_files.tar.gz ./nginx_configs ./nginx_files    # создаем архив с файлами


Эта последовательность команд создаст архив файлов Nginx в две отдельные директории: `nginx_configs` для конфигурационных файлов и `nginx_files` для файлов сайта. Затем архивирует эти директории в архив `nginx_files.tar.gz`.
